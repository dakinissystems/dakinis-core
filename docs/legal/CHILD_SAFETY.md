# Estándares de Seguridad Infantil — Dakinis Core
Última actualización: 2026-05-08

Dakinis Core mantiene tolerancia cero contra la explotación y abuso sexual infantil (CSAE/CSAM).

Se prohíbe cualquier contenido o conducta de grooming, explotación, trata o abuso de menores.

Medidas:
- herramientas de reporte
- revisión y moderación prioritaria
- eliminación de contenido ilegal
- suspensión de cuentas infractoras
- cooperación con autoridades competentes

Contacto de seguridad: legal@dakinis.local
