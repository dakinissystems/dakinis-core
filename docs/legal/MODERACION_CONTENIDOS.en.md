# Content moderation statement — Dakinis Core
Last updated: 2026-05-08

When Dakinis Core operates user-generated-content surfaces, the following baseline applies:

- prohibition of illegal content, abuse, fraud, and malware
- reporting, review, and moderation actions
- cooperation with authorities when legally required

Possible actions: hide/remove content, account restrictions, and suspension.

Legal/moderation contact: legal@dakinis.local
