# Declaración de moderación de contenidos — Dakinis Core
Última actualización: 2026-05-08

Cuando Dakinis Core opere superficies con contenido generado por usuarios, se aplican estas reglas base:

- prohibición de contenido ilegal, abuso, fraude y malware
- posibilidad de reporte, revisión y acciones de moderación
- cooperación con autoridades cuando exista obligación legal

Medidas posibles: ocultación/eliminación de contenido, restricciones y suspensión de cuentas.

Contacto legal/moderación: legal@dakinis.local
