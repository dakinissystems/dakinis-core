# Política de Privacidad — Dakinis Core
Última actualización: 2026-05-08

Dakinis Core recopila y trata datos personales para operar su plataforma SaaS multi-tenant.

## 1. Responsable
- Responsable: Dakinis Systems
- Contacto privacidad: privacy@dakinis.local
- Jurisdicción base: España

## 2. Datos tratados
- Cuenta: nombre, email, identificadores de autenticación.
- Operación: IP, logs, sesiones, trazas técnicas.
- Contenido funcional: datos necesarios para módulos y verticales del sistema.

## 3. Finalidad
- Prestar el servicio.
- Seguridad, prevención de abuso y cumplimiento legal.
- Mantenimiento técnico y mejora operativa.

## 4. Base legal
- Ejecución de contrato.
- Interés legítimo.
- Cumplimiento de obligaciones legales.
- Consentimiento cuando aplique.

## 5. Conservación
Se conservan datos mientras exista relación de servicio o obligación legal/seguridad aplicable.

## 6. Cesiones
Podemos compartir datos con proveedores de infraestructura y autoridades cuando exista obligación legal.
No vendemos datos personales.

## 7. Derechos
Puedes solicitar acceso, rectificación, supresión, oposición, limitación y portabilidad en `/legal/dpo`.

## 8. Cookies y almacenamiento
La web puede usar almacenamiento técnico para sesión y preferencias. Ver `/legal/cookies`.

## 9. Contacto
Consultas de privacidad: privacy@dakinis.local

Nota: documento informativo, no asesoría legal profesional.
