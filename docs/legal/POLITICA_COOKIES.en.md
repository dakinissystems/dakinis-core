# Cookie policy and local storage — Dakinis Core
Last updated: 2026-05-08

This document describes cookie and local storage usage in Dakinis Core web surfaces.

## 1. Technical use
Technical storage may be used for:
- session/authentication
- UI preferences
- consent state

## 2. Optional categories
If non-essential analytics/marketing is enabled, it should be activated only with consent where required.

## 3. Management
You can accept, reject, or configure cookies via the banner and browser settings.
